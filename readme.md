# Spotify Dataset - Exploratory Data Analysis

## Overview

This project performs Exploratory Data Analysis (EDA) on a Spotify dataset containing information about songs, artists, genres, popularity, and audio features.

## Objectives

- Understand the structure of the dataset
- Analyse missing values and duplicates
- Study distributions of Spotify audio features
- Analyse song popularity
- Explore relationships between audio features
- Identify potential outliers
- Compare popularity across genres

## Analysis Performed

- Dataset overview
- Descriptive statistics
- Univariate analysis
- Artist analysis
- Explicit vs non-explicit analysis
- Bivariate analysis
- Correlation analysis
- Outlier analysis
- Genre analysis

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
